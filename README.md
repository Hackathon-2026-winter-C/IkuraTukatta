# いくらつかった

## 想定ユーザー

- 家計簿を始めたいが、続かずに挫折してきた人

## 課題

入力や管理の手間が多く、情報が散らかって把握しづらい状況が続いている。  
その結果、「管理したいのに続かない」と感じてしまう。

## 解決策

口座連携や難しい設定をせず、レシートを取り込むだけで簡単に管理できる仕組みを提供。  
「何にいくら使っているか」を自然に自覚できる状態を作る。

## 主要機能

### 認証・アカウント

- ログイン
- ログアウト
- アカウント登録
- Google ログイン

### 家計管理

- 支出入力
- 収入入力
- レシート入力
- 支出・収入の編集、削除

### 可視化

- カレンダー表示
- リスト表示
- チャート表示

### その他

- グループ家計簿
- プロフィール編集
- 名前変更
- メールアドレス変更
- パスワード変更
- カラーモード選択
- アカウント削除
